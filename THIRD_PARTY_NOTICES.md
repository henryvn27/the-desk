# Third-party notices

The full Electron rebuild does not include the legacy native overlay adaptation. Historical notices remain with that source in Git history. Runtime dependency notices must be collected from the exact packaged dependency set and reviewed before release; this file is not a completed license audit.

Canvas embeds Excalidraw 0.18.1 (MIT), https://github.com/excalidraw/excalidraw. Its MIT license is retained in `licenses/Excalidraw.txt` and packaged as a resource. Font and transitive dependency license inventory remains a public-release verification item.

Math blocks use @mathjax/src 4.1.3 and @mathjax/mathjax-tex-font 4.1.3. Both npm packages declare Apache-2.0. The Apache license text from @mathjax/src is retained in `licenses/MathJax.txt` and packaged as a resource. The font package does not ship a separate license file; its package-declared license and the complete transitive/font notice inventory still require release review. MathJax: https://www.mathjax.org/.
